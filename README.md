# Video editor portfolio

## Run locally

1. Install Node.js (18 or newer).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

The production build is in `dist/`. To recreate it, run `npm run build`.

The `.env.example` file is a template only. Copy it to `.env` and set your own values if you configure the contact API.
